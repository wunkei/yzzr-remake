# 《勇士的信仰》（BraveMan III）基础移动与动作手感核心移植

基于原版 SWF 反编译数据（ActionScript 3.0）与嵌入式二进制配置（`binaryData/7453_src.Data2_jnData0.bin`）实现的 2D 横版动作 ARPG 核心手感与物理切片。

---

## 一、 已实现的必要核心功能清单

1. **原版 XML 技能动作数据驱动 (`skill_loader.py`)**：
   - 直接读取并解析原版 `7453_src.Data2_jnData0.bin`。
   - 提取 21 种动作标签的关键帧定义、持续帧、位移向量（`move_x`, `move_y`, `move_dur`）、伤害系数（`hp_ratio`）、击退力（`knockback`）、挑高浮空力（`knockup`）与受击硬直（`hitstun`）。

2. **输入管理器与按键检测 (`input_manager.py`)**：
   - 还原原版 `BasicKey.as` 判定时序：
     - 单次瞬按（Just Pressed）：攻击、跳跃、技能。
     - 持续按住（Holding）：左右行走、持续冲刺。
     - **双击冲刺检测（Double Tap）**：在 300ms 阈值内双击 `A` 或 `D` 触发进入高速冲刺（Dash/Run）状态。

3. **物理运动与多层平台吸附 (`physics.py`)**：
   - 还原原版动态外力队列 `runArr`：外力随持续帧推进衰减（冲刺推力、受击击退力）。
   - 真实重力加速度计算（`gravity * gravity_acc`）。
   - 主地面吸附与中层战术跳台碰撞。
   - **单向跳台下穿**：按住 `S` + `K` 触发下穿平台。

4. **动作状态机与普攻 4 连击机制 (`player.py`)**：
   - 还原原版 `Skin.OtherGoTo` 连招缓冲区：
     - 普攻 4 连段：`攻击1` $\to$ `攻击2` $\to$ `攻击3` $\to$ `攻击4`。
     - 攻击位移推进：攻击2/3前突滑步（25px），跑攻大突进（150px）。
     - 冲刺派生技：冲刺状态下按 `J` 直接触发【跑攻】。
     - 技能派生：按 `U` 触发【上挑】（浮空挑高 210），按 `I` 触发【下斩】（强力击退 180）。

5. **打击判定与打击感反馈 (`dummy.py` & `main.py`)**：
   - 动态生成帧精度攻击判定盒（Hitbox）与角色躯干受击盒（Hurtbox）。
   - 原版伤害减法防御公式：$\text{有效伤害} = \max(1, \text{攻击} - \text{防御})$。
   - 击退、挑高浮空、受击硬直、受击白闪、伤害跳字（Damage Numbers）与打击震屏（Screen Shake）。

## 二、 键盘操作指南

| 按键 | 对应动作 | 说明 |
| :--- | :--- | :--- |
| **A / D** | 左右移动 (Walk) | 基础水平移动 |
| **双击 A / D** | **冲刺 (Dash / Run)** | 300ms 内双击触发高速拖刀奔跑 |
| **K** | 跳跃 (Jump) | 跳跃上升与下落重力加速度 |
| **S + K** | 下穿平台 | 从悬空跳台向下穿透降落 |
| **J** | **普通攻击 4 连击** | 1~4段连招节奏，带连击输入缓冲与前突位移 |
| **冲刺中按 J** | **跑攻 (Dash Attack)** | 冲刺突进拔刀横斩 |
| **U** | 上挑 (Upper Slash) | 浮空挑高（挑高值 210），用于浮空连击 |
| **I** | 下斩 (Down Slash) | 强力下劈重击（击退值 180） |
| **H** | 切换判定框显示 | 绿框=Hurtbox(受击)，红框=Hitbox(攻击)，黄框=目标 |
| **R** | 重置场景位置 | 将玩家与训练木桩位置复位 |
| **ESC** | 退出程序 | 退出 Demo |
